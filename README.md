A Data-Driven Framework for Quantifying Epistemic Uncertainty in Ground Motion Models for Induced Seismicity in Central and Eastern United States

###########################################################################################

###################### Overview ######################

This repository accompanies the study by Kowsari et al. (????), “A Data-Driven Framework for Quantifying Epistemic Uncertainty in Ground Motion Models for Induced Seismicity in the Central and Eastern United States (CEUS).” It includes the dataset used in the study.

######################

Folder Structure

######################
Combined_Flatfile

This file contains the dataset used in the analysis. It was compiled from Thompson et al. (2023).
